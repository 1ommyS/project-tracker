# Changelog

Все заметные изменения Trace. Формат хранилища остаётся совместимым с Obsidian; старые vault-ы читаются без миграций.

## Следующий релиз

### Trace Desktop
- Установлена новая иконка с диаграммой из последнего предоставленного изображения: центральный квадрат без растягивания, все размеры AppIcon и отдельный ресурс Dock.
- Приложение переименовано в «Trace Desktop»: обновлены системное имя, пакет .app, меню и названия релизных архивов. Схема Xcode, модуль, bundle identifier, настройки и доступ к существующему хранилищу сохранены.

### Ширина таблицы и новая иконка
- При запуске приложение явно устанавливает иконку Dock из текущей сборки, чтобы старый кэш macOS не скрывал новый логотип при Run из Xcode. Системное имя — «Trace Desktop»; идентификатор приложения и пользовательские настройки сохранены.
- Таблица статусов, список записей, поиск и кнопки выровнены по одному центральному контейнеру шириной до 1000 точек. На широком окне таблица больше не растягивается на весь экран; дополнительные дни прокручиваются внутри контейнера.
- Иконка приложения заменена на предоставленный логотип; обновлены все размеры AppIcon от 16 до 1024 пикселей.

### Таблица и список статусов, отзывчивость
- Новый раздел «Статусы» (⌘6): таблица «проекты × дни» и список полных записей за выбранную дату. Режим запоминается. В таблице доступны 3/5/7 дней, поиск, фильтры блокеров/пропущенных записей и открытие редактора из ячейки.
- «Сегодня» стал компактнее: срочные задачи видны раньше, сводка статусов открывается отдельной командой. Переключатель плотности показывается только там, где влияет на содержимое.
- Для таблицы используется нативный Table; выдержки и индекс дат готовятся вне главного потока. Ленты проектов и записей загружают содержимое по мере прокрутки.
- Повторное обновление хранилища не читает/не разбирает неизменённые Markdown-файлы; внешние правки, удаление, смена vault и переносы инвалидируют кэш. Сводки проектов/задач переиспользуются между обновлениями.
- Убраны повторные разборы быстрого ввода и обновления подсветки без изменений. Очередь уведомлений пропускает устаревшую работу и не пересобирается после правок статуса.
- Архивирование больше не блокирует главный поток; интерфейс показывает ход операции.
- 104 теста покрывают хранилище, кэш, сводки задач, оба представления статусов и адаптивную панель управления; подписанная локальная сборка также проверена в окне приложения.
- На тестовом хранилище из 1 240 Markdown-файлов повторная загрузка сократилась примерно с 374 до 48 мс в Debug. Это замер загрузки, не частоты кадров; методика — docs/PERFORMANCE.md.

### Быстрый ввод, Confluence и стабильность редактирования
- «Быстрый статус» открывается в отдельном небольшом окне через ⌘⇧S, тулбар или строку меню macOS, даже из другого приложения. ⌘↩ дополняет запись выбранного дня; прежний текст, блокеры и чекбоксы сохраняются. Черновик остаётся при закрытии окна до выхода из Trace.
- В меню «Статусы» и «Справка» — гайд по переносу из Confluence: выбор проекта/даты, копирование промпта, готовый формат ответа модели. Быстрый ввод принимает обычную заметку или ## Статус / ## Блокеры, без сетевых подключений.
- Полезные ссылки можно добавлять, переименовывать и менять адрес в отдельной форме; поддержана вставка Markdown-ссылки. ID ссылки сохраняется при правке.
- Задачи и артефакты сохраняют ID между перечитываниями Markdown благодаря невидимым комментариям; старые файлы без них читаются со стабильными ID. Это устраняет пересоздание строк и потерю привязки уведомления к задаче.
- Убраны анимации на каждом символе, изменение ширины быстрого ввода и исчезновение Markdown-тулбара при просмотре. Разделы статуса/блокеров переключаются в редакторе одинакового размера.
- Уведомления больше не планируются для завершённых проектов; расписание обновляется последовательно. Действие «Выполнено» идемпотентно и работает после перезапуска, события при запуске ждут загрузки хранилища.
- В настройках — количество ожидающих напоминаний, ближайший срок, состояние баннеров и фактическая проверка доставки теста. Автотесты уведомлений изолированы от реального расписания macOS. Проверены 92 теста и реальная доставка теста в локально подписанной сборке; в README добавлена команда для такой проверки.

### Навигация и проекты
- Клик по названию, иконке или строке проекта в боковой панели открывает проект. Выбор поддерживает стрелки клавиатуры и системное выделение; переименование вынесено в явную команду и контекстное меню.
- Порядок проектов внутри квартала закреплён по названию: сохранение задачи или статуса не переставляет строки под курсором.
- Один переход создаёт один шаг в истории «Назад/Вперёд». Раздел «Проекты» всегда открывает общий список; архивные проекты доступны для просмотра.
- Убран второй список проектов внутри экрана проекта и плавающая мини-навигация поверх содержимого. Боковая панель скрывается и возвращается штатными средствами macOS.
- Для создания проекта достаточно названия. Эпик, родительский проект, описание и теги убраны из интерфейса; существующие значения, ссылки и старые разделы Markdown сохраняются при записи.
- Название задачи открывает единый редактор; выполнение и изменение срока остаются отдельными действиями. Кнопки получили доступные подписи; системный курсор больше не переопределяется глобально.

### Дневные статусы и Markdown
- Доступны таблица проектов по дням и крупные карточки за выбранный день в списочном режиме. Календарь и кнопки предыдущего/следующего дня позволяют открыть любую дату; блокеры относятся именно к выбранному дню.
- Статус и блокеры редактируются вместе в просторном окне с «Сохранить» / «Отмена». Дата фиксируется при открытии; ошибка записи сохраняет черновик. Чекбоксы можно менять и удалять в исходном Markdown.
- Markdown-редактор использует прокручиваемое текстовое поле AppKit с переносами, стандартным Undo/Redo и корректным выделением emoji. Форматирование списков применяется ко всем выделенным строкам.
- Локальный предпросмотр показывает заголовки, абзацы, списки, цитаты, код и встроенное форматирование. Заголовки внутри текста и служебные заголовки внутри fenced code больше не обрывают запись при чтении.
- Перед записью проверяются незакрытые блоки кода и зарезервированные заголовки разделов: неоднозначный текст остаётся в черновике с объяснением, предыдущая запись сохраняется.
- Записи одного проекта выполняются последовательно: быстрые правки задач, статусов и названия не затирают друг друга. После архивации/восстановления пути к дневным статусам обновляются вместе с папкой проекта.

### Прочее
- Уведомления запрашиваются при назначении напоминания или явно в настройках; запуск больше не открывает Системные настройки.
- Сохранены режимы «Фокус» / «Подробно», дашборд «Просрочено», быстрый ввод сроков и выгрузка архива хранилища.
- Расширены тесты навигации, сохранения, совместимости, Markdown и узких раскладок. Обновлены инструкции AGENTS.md / CLAUDE.md.

## v0.1.16 — 2026-10-12

### Сроки — поповером с большим календарём
- Клик по бейджу срока открывает поповер в духе Reminders: полноценный графический календарь на месяц, отдельная строка времени, кнопки «Готово» (Return), «Отмена» и «Убрать срок» для задач с дедлайном.
- Esc и клик мимо закрывают поповер без изменений — случайных правок больше нет.
- Работает во всех местах: лента, редактор проекта, все секции «Сегодня». У задач без срока колокольчик «Срок» появляется при наведении на строку.

## v0.1.15 — 2026-10-12

### Цветовые палитры
- 12 акцентных палитр на выбор: синий, фиолетовый, розовый, красный, оранжевый, жёлтый, зелёный, мятный, бирюзовый, голубой, индиго, графитовый. Выбор — свотчами в настройках, применение мгновенное, сохраняется между запусками.
- Палитра красит кнопки и glass-элементы, ссылки-пути проектов, теги, бейджи сроков, подсветку распознанных дат в поле ввода, кольцо прогресса и цвет активного состояния проекта. Семантика не ломается: просроченное — красное, завершённое — зелёное, палитра отвечает только за акцент.
- Палитры построены на системных цветах — автоматически адаптируются к светлой/тёмной теме.

### Релизы
- Описания релизов в CI берутся из `releases/<version>.md` с фолбэком на автогенерацию GitHub; добавлен шаблон `releases/EXAMPLE.md`.

## v0.1.9 — 2026-10-12 — релиз Trace

Большое обновление: приложение переименовано в **Trace** и переработано от модели данных до визуального языка. Внутренние идентификаторы (bundle id, путь хранилища) не менялись — данные, настройки и разрешения уведомлений сохраняются.

### Фокус на задачах
- Ежедневные статусы, заметки проектов и экран «Активность» убраны; формат `Project.md` упрощён до описания и задач, старые файлы читаются без ошибок.
- Экран «Сегодня» — про задачи: просроченные, сегодняшние, предстоящие (неделя) и «без срока»; бейдж срочных задач в навигации.
- Лента проектов: каждый проект — карточка со своими задачами, прогрессом, тегами и полем быстрого добавления.

### Кварталы
- Хранилище разложено по кварталам создания: `Projects/26Q4/<slug>/`; завершённые проекты автоматически переезжают в `Completed Projects` своего квартала, возврат в активные возвращает папку. Slug папки стабилен при переносах.
- Старая плоская структура читается и мягко мигрирует при первом сохранении.
- Папки-кварталы видны во всей навигации (сайдбар, список редактора, лента, архив) + динамический фильтр по кварталам.

### Редактирование
- Режим «Редактор»: список проектов + инлайн-редактор справа; название, иерархия, описание и теги правятся на месте с автосохранением.
- Инлайн-переименование проектов и задач в любой точке: клик по тексту — поле ввода; Return — сохранить, Esc — отменить; при наведении плашка и карандаш.
- Умный ввод сроков: «завтра 18:00», «25.12», «в 14» превращаются в напоминание; прошедшее время переносится на завтра.

### Уведомления
- Починена доставка: делегат подключается лениво, разрешение запрашивается при первом запуске, ошибки логируются и видны в настройках.
- Клик по уведомлению открывает проект; кнопка «Выполнено» закрывает задачу прямо из баннера; в настройках — тестовое напоминание для мгновенной проверки.

### Навигация и оформление
- История «Назад/Вперёд» (⌘[/⌘]), ⌘T/⌘N/⌘E, ⌘1…⌘4, памятка горячих клавиш.
- Системный стиль macOS: палитра и фон, нативный сайдбар-лист, тулбарные заголовки, единая сетка отступов, плавные анимации с уважением к «Уменьшить движение».
- Исправлены залипающие курсоры (стрелка после полей ввода, рука над строками), «прыгающие» при вводе списки и неработающая кнопка состояния.
- 27 тестов: кодек Markdown, парсер сроков, репозиторий (кварталы, переносы, миграция), стор (CRUD, история навигации, поиск).
