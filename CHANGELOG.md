# Changelog

Все заметные изменения Trace. Формат хранилища остаётся совместимым с Obsidian; старые vault-ы читаются без миграций.

## [Unreleased] — 2026-10-12

### Переименование

- Приложение переименовано в **Trace** (ранее PROJECT Tracking): имя в меню, окнах, настройках и релизных артефактах (`Trace.app`, `Trace.zip`, `Trace.dmg`).
- Внутренние идентификаторы (bundle id, путь хранилища, Swift-модуль) не менялись — существующие данные, настройки и разрешения уведомлений сохраняются.

### Фокус на задачах

- Приложение упрощено до проектов и задач: ежедневные статусы, заметки проектов и экран «Активность» убраны. Формат `Project.md` стал проще, старые файлы читаются без ошибок.
- Экран «Сегодня» теперь про задачи: секции «Просроченные», «Задачи на сегодня», «Предстоящие» (неделя) и «Без срока»; бейдж срочных задач на элементе «Сегодня» в навигации.
- Лента «Проекты»: каждый проект — карточка со своими задачами, прогрессом, тегами и полем быстрого добавления.

### Редактирование

- Новый режим **«Редактор»**: список проектов + инлайн-редактор справа. Название, эпик, проект, описание и теги правятся прямо на месте с автосохранением; состояние переключается мгновенно.
- **Инлайн-переименование везде**: клик по названию проекта (лента, сайдбар, редактор, архив) или задачи (лента, «Сегодня», редактор) превращает его в поле ввода. Return — сохранить, Esc — отменить; при наведении появляется плашка и карандаш.
- Единый редактор задачи: выбор проекта, пресеты срока («Сегодня», «Завтра», «Через неделю»), удаление, подсказка при выключенных уведомлениях.

### Умный ввод сроков

- В поле быстрого ввода распознаётся срок естественным языком: «Позвонить завтра 18:00», «Сдать 25.12», «Созвон в 14». Распознанный срок показывается бейджем до добавления; прошедшее время переносится на завтра.

### Кварталы

- Хранилище разложено по кварталам создания: `Projects/26Q4/<slug>/`; завершённые проекты автоматически переезжают в `Projects/<YYQN>/Completed Projects/`, возврат в активные возвращает папку на место. Имя папки стабильно при переносах; плоская старая структура читается и мягко мигрирует.
- Папки-кварталы видны во всей навигации: сайдбар, список редактора, лента и архив группируются сворачиваемыми секциями `26Q4 ›`. В шапке «Проектов» — динамический фильтр по кварталам.

### Уведомления (напоминания)

- Исправлена доставка: подключение делегата центра уведомлений перенесено на момент реального использования, разрешение запрашивается при первом запуске, ошибки планирования логируются и видны в настройках.
- Нажатие на уведомление открывает проект; кнопка **«Выполнено»** прямо в уведомлении закрывает задачу.
- В настройках появилась кнопка **«Отправить тестовое напоминание»** — баннер через 5 секунд для мгновенной проверки доставки.

### Навигация

- История переходов как в браузере: **⌘[** / **⌘]** и кнопки «Назад/Вперёд» в тулбаре.
- Быстрый доступ к проектам из сайдбара; при свёрнутом сайдбаре слева появляется мини-панель быстрой навигации.
- ⌘T — новая задача, ⌘N — новый проект, ⌘E — недавние проекты, ⌘1…4 — экраны; памятка горячих клавиш обновлена.

### Оформление

- Интерфейс приведён к системному стилю macOS: системная палитра и фон, нативный сайдбар-список с translucent-выделением, заголовки экранов в тулбаре, карточки в духе группированных секций без теней и обводок.
- Плавные анимации по всему приложению: переключение экранов, появление задач и карточек, зачёркивание выполненных, `numericText`-счётчики; уважается системная настройка «Уменьшить движение».
- Выправлены выравнивания: единая сетка отступов, ширина заголовков совпадает с шириной контента, экран помощи перестроен на выровненную таблицу.
- Курсоры по правилам macOS: рука над кликабельными строками, стрелка при уходе с полей ввода, I-beam только внутри редактора.

### Исправления

- Навигация «Назад/Вперёд» корректно шагает по истории (раньше застревала после первого шага).
- Убрано «дрожание» списков и каретки при автосохранении: порядок массива проектов больше не пересортируется при каждом сохранении; список редактора отсортирован по алфавиту и стабилен.
- Кнопка состояния проекта работает во всех местах (раньше дублированные контролы перехватывали клики).
- Переименование продукта не ломает тесты: явная shared-схема с тестовым действием, `TEST_HOST` не зависит от имени приложения.

### Внутреннее

- 27 юнит- и интеграционных тестов: кодек Markdown, парсер сроков, репозиторий (кварталы, переносы, миграция легаси), стор (CRUD задач, переименования, история навигации, поиск, стабильность порядка).
- Рефакторинг UI: общие компоненты (`InlineEditableText`, `ProjectStateMenu`, `QuarterGroupLabel`, `TaskListSection`), единые метрики вёрстки и правила стиля зафиксированы в AGENTS.md.
