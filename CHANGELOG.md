# Changelog

Все заметные изменения Trace. Формат хранилища остаётся совместимым с Obsidian; старые vault-ы читаются без миграций.

## Следующий релиз

### Хранилище и задачи
- **Выгрузка архива хранилища** в настройках: rar при установленном `rar` (brew install rar), иначе zip с метаданными — для безопасной репликации между обновлениями.
- **«Весь день»**: задача с датой без времени висит весь день (срок 23:59, бейдж «весь день»), напоминание — в 9:00 утра, а не в полночь.
- **Артефакты-гиперссылки**: у проекта — раздел `## Артефакты` со ссылками (Figma, документы, репозитории); добавление, переход и удаление прямо в редакторе.

### Матрица статусов
- Ячейки больше не обрезаются: длинные статусы, блокеры и чекбоксы показываются целиком.
- Статусы рендерятся как **Markdown** (жирный, курсив, ссылки, код).
- **Markdown-редактор** в «Статусах по дням» проекта: тулбар (жирный, курсив, зачёркнутый, код, заголовок, список, чекбокс, цитата, ссылка) оборачивает выделение, кнопка предпросмотра показывает итоговый вид; автосохранение с задержкой. Тулбар и переключатели дней — единые стеклянные полосы с hover-чипами в стиле мини-навигации. Поле больше не схлопывается при вводе и не пересоздаётся при переключении предпросмотра; операции тулбара вынесены в чистые `MarkdownTextOps` под тестами (8 кейсов).
- В сегодняшней ячейке — задачи проекта «на сегодня»: назначенные на день (иконка-часы) и без срока (пунктирный кружок).

### Контекстные меню (двухпальцевый тап / правый клик)
- **Проекты** (везде — сайдбар, лента, список редактора, матрица): открыть в редакторе, переключить состояние (с галочкой текущего), архивировать/вернуть, новая задача…, показать папку в Finder, копировать название, удалить с подтверждением.
- **Задачи** (лента, «Сегодня», «Просрочено»): выполнить, подменю «Срок» — сегодня/завтра «весь день», через неделю, убрать, выбрать в календаре…; редактировать, дублировать, копировать название, удалить.
- **Ячейки матрицы статусов**: копировать статус (в т.ч. вместе с задачами), очистить день.
- **Артефакты**: открыть, копировать ссылку, убрать.

### Прочее
- Уведомления: при каждом запуске без разрешения (с повторной проверкой статуса — без ложных срабатываний при выданном разрешении) открывается панель «Уведомлений» в Системных настройках; расписание пересобирается при каждой активации окна (выдача разрешения подхватывается без перезапуска).
- Переход между проектами в редакторе — с плавной пружинной анимацией (сдвиг+растворение).
- Мини-навигация при свёрнутом сайдбаре — узкая стеклянная шторка только с иконками: один материал, выделение текущего экрана цветом палитры, красная точка просрочек, курсор-рука на иконках.

### Гибкость: два режима интерфейса
- В тулбаре появился переключатель видов — «Фокус» (иконка прицела) и «Подробно» (иконка списка). Выбор запоминается между запусками.
- **Фокус** — режим работы без отвлечений: экран «Сегодня» показывает только просроченные и сегодняшние задачи, без приветствия, кольца прогресса и метрик; когда срочного нет — спокойное «Всё под контролем». Лента проектов сворачивается в компактные строки: символ состояния, название, квартал, счётчик открытых задач — быстрое сканирование всех проектов одним взглядом.
- **Подробно** — прежний полный вид: приветствие и прогресс дня, метрики, секции «Предстоящие» и «Без срока», карточки проектов с задачами, тегами и полем быстрого добавления.
- В фокусном виде строки проектов по-прежнему живые: клик по названию переименовывает, меню состояния переключает его, клик по строке открывает редактор.

### Матрица статусов: проект × дни
- На «Сегодня» статусы перестроены в матрицу: строки — проекты, колонки — последние 5 дней (сегодня подсвечена), отдельная колонка **«Блокеры»**. В каждой ячейке — статус проекта на этот день.
- Дни идут по убыванию: сегодня — первая колонка слева.
- Любая ячейка правится инлайн (клик → поле, Return — сохранить); блокеры пишутся в сегодняшний статус и показываются красным.
- Матрица статусов стала крупнее (шрифт callout, шире колонки) — читается без напряжения.
- Мини-навигация при свёрнутом сайдбаре вернулась: glass-панель с подписями экранов, бейджем просрочек и кнопкой возврата панели.
- В редакторе проекта — секция «Статусы по дням»: статус, блокеры и чекбоксы за любую дату (выбор через календарь или быстрые кнопки последних дней).
- **Чекбоксы в статусах**: строки «- [ ] задача» внутри дневного статуса показываются в ячейках матрицы как отмечаемые чекбоксы; можно печатать их прямо в тексте ячейки — при сохранении они станут задачами.
- Хранение: `Statuses/YYYY-MM-DD-<8hex>.md` с разделами `## Статус` и `## Блокеры` — совместимо с Obsidian, один файл на день.

### Заметки по статусу проектов
- У каждого проекта — короткая заметка «что сейчас» (`## Статус` в Project.md, совместимо с Obsidian): редактируется инлайн прямо в сводке статусов на «Сегодня», в списке редактора и полем в самом проекте.
- В сводке «Статусы проектов» теперь видна последняя заметка по каждому проекту, а не только состояние и прогресс.

### Матрица статусов: задачи без срока в сегодняшней колонке
- В матрице «Статусы по дням» сегодняшняя ячейка показывает под статусом все открытые задачи проекта без даты окончания (пунктирный кружок) — видно, что висит, прямо при заполнении статуса; клик отмечает выполненной.

### Главная: статусы проектов и русские даты
- На экране «Сегодня» (подробный вид) появилась сводка «Статусы проектов»: все активные проекты с состоянием, кварталом, прогрессом задач и временем последнего обновления; клик по строке открывает редактор.
- Все даты в интерфейсе — по-русски: заголовок дня («воскресенье, 12 октября»), месяцы в сроках («20 окт.»), относительное время («5 мин назад», «вчера»). Приложение не локализовано как бандл, поэтому локаль задаётся явно.

### Дашборд «Просрочено»
- Новая вкладка (⌘3) собирает все пропущенные сроки со всех проектов: группировка по проектам, самые старые — сверху, у каждой строки — на сколько дней просрочен срок.
- **Гистограмма просрочек по дням** (Swift Charts): сколько задач не закрыто в срок по каждому дню дедлайна — от самого старого до сегодня; клик/наведение по столбцу показывает этот день и названия задач, сегодня подсвечено ярче.
- Инлайн-действия прямо из дашборда: выполнить, переименовать, перенести срок поповером, удалить; клик по заголовку проекта открывает редактор.
- Пустое состояние без просроченных — «Все задачи в срок». Бейдж счётчика в боковой панели.

### Навигация по канонам macOS
- Плавающая мини-панель (появлялась при свёрнутом сайдбаре) удалена — вместо неё стандартное меню навигации в тулбаре (иконка сетки).
- Внутри меню — все экраны с галочкой текущего и подсказками ⌘1…⌘4, а также команда «Показать боковую панель». Никаких самодельных элементов — только системные контролы macOS.

### «Что нового» прямо в приложении
- При обновлении версии приложение показывает экран с описанием изменений; открыть вручную можно через Справка → «Что нового в Trace».
- Содержимое экрана автоматически синхронизируется с релизом: CI собирает его из `releases/<version>.md`, а при отсутствии — из этого changelog. Заметки на GitHub и внутри приложения больше не расходятся.

### Внутреннее
- 36 тестов: добавлена проверка сохранения выбранного режима интерфейса.
- Changelog переработан по фактическим релизам (сверка тегов GitHub с коммитами).

## v0.1.16 — 2026-10-12

### Сроки — поповером с большим календарём
- Клик по бейджу срока открывает поповер в духе Reminders: полноценный графический календарь на месяц, отдельная строка времени, кнопки «Готово» (Return), «Отмена» и «Убрать срок» для задач с дедлайном.
- Esc и клик мимо закрывают поповер без изменений — случайных правок больше нет.
- Работает во всех местах: лента, редактор проекта, все секции «Сегодня». У задач без срока колокольчик «Срок» появляется при наведении на строку.

## v0.1.15 — 2026-10-12

### Цветовые палитры
- 12 акцентных палитр на выбор: синий, фиолетовый, розовый, красный, оранжевый, жёлтый, зелёный, мятный, бирюзовый, голубой, индиго, графитовый. Выбор — свотчами в настройках, применение мгновенное, сохраняется между запусками.
- Палитра красит кнопки и glass-элементы, ссылки-пути проектов, теги, бейджи сроков, подсветку распознанных дат в поле ввода, кольцо прогресса и цвет активного состояния проекта. Семантика не ломается: просроченное — красное, завершённое — зелёное, палитра отвечает только за акцент.
- Палитры построены на системных цветах — автоматически адаптируются к светлой/тёмной теме.

### Релизы
- Описания релизов в CI берутся из `releases/<version>.md` с фолбэком на автогенерацию GitHub; добавлен шаблон `releases/EXAMPLE.md`.
- *Сборка v0.1.14 не публиковалась — палитры вошли в v0.1.15.*

## v0.1.13 — 2026-10-12

- В поле быстрого ввода фрагмент «завтра в 18:00» подсвечивается цветом палитры и полужирным прямо по мере набора — сразу видно, что именно поймал парсер.

- Для задач без срока при наведении на строку появляется подсказка «Срок» — назначить дедлайн можно в один клик.
- Напоминания перестраиваются автоматически: задали срок — уведомление запланировано, убрали — снято; первое назначение при неопределённом статусе запросит разрешение на уведомления.

## v0.1.9 — 2026-10-12 — релиз Trace

Большое обновление: приложение переименовано в **Trace** и переработано от модели данных до визуального языка. Внутренние идентификаторы (bundle id, путь хранилища) не менялись — данные, настройки и разрешения уведомлений сохраняются.

### Фокус на задачах
- Ежедневные статусы, заметки проектов и экран «Активность» убраны; формат `Project.md` упрощён до описания и задач, старые файлы читаются без ошибок.
- Экран «Сегодня» — про задачи: просроченные, сегодняшние, предстоящие (неделя) и «без срока»; бейдж срочных задач в навигации.
- Лента проектов: каждый проект — карточка со своими задачами, прогрессом, тегами и полем быстрого добавления.

### Кварталы
- Хранилище разложено по кварталам создания: `Projects/26Q4/<slug>/`; завершённые проекты автоматически переезжают в `Completed Projects` своего квартала, возврат в активные возвращает папку. Slug папки стабилен при переносах.
- Старая плоская структура читается и мягко мигрирует при первом сохранении.
- Папки-кварталы видны во всей навигации (сайдбар, список редактора, лента, архив) + динамический фильтр по кварталам.

### Редактирование
- Режим «Редактор»: список проектов + инлайн-редактор справа; название, иерархия, описание и теги правятся на месте с автосохранением.
- Инлайн-переименование проектов и задач в любой точке: клик по тексту — поле ввода; Return — сохранить, Esc — отменить; при наведении плашка и карандаш.
- Умный ввод сроков: «завтра 18:00», «25.12», «в 14» превращаются в напоминание; прошедшее время переносится на завтра.

### Уведомления
- Починена доставка: делегат подключается лениво, разрешение запрашивается при первом запуске, ошибки логируются и видны в настройках.
- Клик по уведомлению открывает проект; кнопка «Выполнено» закрывает задачу прямо из баннера; в настройках — тестовое напоминание для мгновенной проверки.

### Навигация и оформление
- История «Назад/Вперёд» (⌘[/⌘]), ⌘T/⌘N/⌘E, ⌘1…⌘4, памятка горячих клавиш.
- Системный стиль macOS: палитра и фон, нативный сайдбар-лист, тулбарные заголовки, единая сетка отступов, плавные анимации с уважением к «Уменьшить движение».
- Исправлены залипающие курсоры (стрелка после полей ввода, рука над строками), «прыгающие» при вводе списки и неработающая кнопка состояния.
- 27 тестов: кодек Markdown, парсер сроков, репозиторий (кварталы, переносы, миграция), стор (CRUD, история навигации, поиск).
