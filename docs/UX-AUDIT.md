# Аудит интерфейса Trace — 10 ноября 2026

Проверены боковая панель, список и карточка проекта, создание и переименование, архив, переходы из поиска/недавних проектов, дневные статусы, задачи и Markdown. Решения ниже — применение нативных соглашений macOS к конкретным сценариям Trace, а не заявление о формальной сертификации всего интерфейса по HIG.

## Обратная совместимость

YAML-поля `epic`, `parent_project`, `tags` и старые разделы «Описание», «Статус», «Артефакты» не удаляются при переименовании и изменении задач. Новые проекты записываются с пустыми необязательными полями. Иерархия скрыта только в интерфейсе. Старая плоская структура, кварталы, `Completed Projects`, атомарная запись и удаление через Корзину сохранены.

Имена служебных разделов Markdown зарезервированы форматом. Перед записью проверяются незакрытые блоки кода и служебные заголовки внутри пользовательского текста: неоднозначная запись отклоняется с объяснением, черновик и предыдущий файл сохраняются. Предпросмотр поддерживает основную текстовую разметку, без HTML-рендерера и расширений CommonMark вроде таблиц. Внешние ссылки открываются только по действию пользователя.

## Основания для решений

Основной ориентир — [Apple HIG: Sidebars](https://developer.apple.com/design/human-interface-guidelines/sidebars): нативная боковая панель, краткие подписи, разумная глубина иерархии и доступный показ/скрытие. Для контролов и редактирования — [Buttons](https://developer.apple.com/design/human-interface-guidelines/buttons), [Text fields](https://developer.apple.com/design/human-interface-guidelines/text-fields) и [Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility). Отделение открытия от переименования, фиксированная дата черновика и очередь записи — инженерные решения Trace для предотвращения случайных действий и потери данных.

## Следующая итерация: быстрый ввод и устойчивость

- Источники скачков: случайные ID задач/ссылок при decode, анимация на каждом символе, изменение ширины composer и высоты при скрытии тулбара, два вложенных scroll-контейнера в редакторе статуса. Исправлены стабильными ID и постоянной геометрией контролов; статус/блокеры — равные вкладки.
- Быстрый статус отделён от навигации: небольшое плавающее окно, строка меню macOS и ⌘⇧S; ⌘↩ добавляет запись к выбранному дню. Закрытие сохраняет черновик до выхода из приложения.
- Гайд Confluence доступен отдельно в меню и из быстрого ввода; копирует промпт, привязанный к проекту и дате. Локальный parser принимает ответ модели в двух разделах, не исполняя его содержимое.
- Ссылки получили форму редактирования названия и адреса, проверку URL, вставку Markdown-ссылки и сохранение ID.
- Уведомления проверяются на уровне чистого плана, инъецированного клиента и диагностики macOS; действие «Выполнено» больше не переключает выполненную задачу обратно.

Добавлен отдельный раздел «Статусы» (⌘6) с сохранением предпочтения «Таблица / Список». Сводки за несколько дней и блокеры относятся к датам соответствующих ячеек. «Сегодня» сокращён до рабочей сводки и задач; длинные списки построены лениво. Глобальный переключатель плотности скрыт на экранах, где он ничего не меняет.

В окне приложения проверены: ⌘6, переключение двух видов, поиск по тексту статуса, сохранение запроса при смене вида, семь колонок/горизонтальная прокрутка, открытие редактора даты из ячейки и отмена, сохранение списочного вида после перехода на другой экран. Тестовые черновики не записывались. Панель управления имеет отдельную проверку ширины 440 pt.

Исправлены полное повторное чтение хранилища, повторные производные сводки и разбор ввода, очередь устаревшей синхронизации уведомлений и блокировка main thread при архивировании. Кэш покрыт проверками внешних правок/удалений/смены vault; записи по-прежнему атомарны. Методика, числа и ограничения — [PERFORMANCE.md](PERFORMANCE.md). Холодная загрузка в замере не ускорилась; ускорение повторного чтения не выдается за измерение FPS.

### Общая ширина раздела статусов

Панель поиска и кнопок, таблица/список и нижняя строка используют один центрированный контейнер `PulseMetrics.contentWidth` (1000 точек) с внешним отступом `PulseMetrics.screen`. На широком окне края совпадают; в узком окне элементы управления переносятся, а дополнительные колонки прокручиваются внутри таблицы.

### Иконка при Run из Xcode

В AppIcon.icns собранного пакета подтверждён новый рисунок. macOS регистрирует несколько старых копий с тем же bundle identifier; это возможный источник устаревшего значка. Теперь `TraceAppDelegate` при старте задаёт `NSApplication.applicationIconImage` из локального `Resources/TraceLogo.png` текущего пакета, не меняя идентификатор/доступ к vault. Это штатный [API иконки Dock](https://developer.apple.com/documentation/appkit/nsapplication/applicationiconimage). 10 ноября проверены Stop → Run в Xcode и новый логотип в About Trace; 104 теста прошли.
