# Как перенести статус из Confluence через модель

1. Откройте в Trace «Статусы → Гайд: статусы из Confluence…».
2. Выберите проект и дату и нажмите «Копировать промпт».
3. В привычном приложении модели вставьте промпт; замените последний placeholder на скопированный текст нужной страницы Confluence.
4. Скопируйте ответ модели. В Trace нажмите ⌘⇧S; из другого приложения откройте «Быстрый статус…» через значок Trace в строке меню macOS.
5. Проверьте проект и день в окне быстрого ввода, вставьте ответ и нажмите ⌘↩.

Ожидаемый ответ модели:

```markdown
## Статус
- Согласован макет главной страницы.
- Следующий шаг: проверить интеграцию.
- [Макет](https://example.com/design)

## Блокеры
- Не выдан доступ к тестовому стенду.
```

Если блокеров нет, раздел можно оставить пустым. Для короткой заметки достаточно обычного текста — заголовки не обязательны. Незакрытые блоки кода или повторные служебные разделы показывают ошибку; исходный черновик остаётся в окне.

Заметка **дополняет**, а не заменяет ранее сохранённый статус дня. Для исправления прежнего текста откройте «Редактировать» в карточке дня. Полезные ссылки из заметки остаются Markdown-ссылками; постоянные артефакты проекта добавляются в раздел «Полезные ссылки» отдельной командой.

Закрытие окна быстрого ввода сохраняет несохранённый черновик в памяти до выхода из Trace. После сохранения окно закрывается, основной экран и выбор проекта не меняются. Приложение само не читает Confluence и не отправляет данные модели.
